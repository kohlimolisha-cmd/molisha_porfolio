MOLISHA KOHLi — PORTFOLIO WEBSITE
=================================

HOW TO RUN
1. Extract the ZIP folder.
2. Open the "molisha-portfolio" folder.
3. Double-click index.html to open it in your browser.
4. For the best development experience, open the folder in VS Code and use the Live Server extension.

FOLDER STRUCTURE
- index.html       Main website
- css/style.css    Layout, colours, responsive styling and animations
- js/script.js     Mobile menu, scroll reveal and active navigation
- assets/          Place your own images and files here

CUSTOMIZE BEFORE PUBLISHING
- Replace hello@example.com with your real email in index.html.
- Add your LinkedIn profile URL.
- Add a CV file and link the "Download CV" button if you want one.
- Update project links and descriptions if needed.
- The hero and project preview artwork is made with CSS, so no image assets are required.

NOTES
- Google Fonts and Lucide icons load from online CDNs.
- The layout is responsive for desktop, tablet and mobile screens.
- This is a front-end static portfolio; the contact button opens the visitor's email app.
